# Journali
<img width="2400" height="1200" alt="journali-banner" src="https://github.com/user-attachments/assets/beacced1-7f4b-4267-8c07-7cebd9ab1705" />


Journali is a simple iOS journaling app that lets you write down your daily thoughts and keep them organized in one place. You can bookmark your favorite entries, search through them, and sort them the way you like.

## Main Features

- **Write journals:** Add a new journal with a title and text, and the date is saved automatically.
- **Bookmark:** Tap the bookmark icon on any journal to mark it as a favorite.
- **Sort:** Use the filter icon to sort journals by bookmark or by entry date.
- **Search:** Find any journal quickly by its title or text.
- **Swipe to delete:** Swipe a journal card to reveal the delete button, then confirm in the alert.
- **Discard protection:** An alert asks for confirmation before discarding unsaved changes.
- **Welcome screen:** A short splash screen when the app opens.

## Technologies Used

- Swift
- SwiftUI
- MVVM architecture
- Combine (`ObservableObject` and `@Published`)
- Liquid Glass (`glassEffect`)
- SF Symbols
- Xcode
